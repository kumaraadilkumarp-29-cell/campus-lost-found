==============================================================
  CAMPUS LOST & FOUND PORTAL  -  START HERE
==============================================================

A complete full-stack application: Express API + MongoDB + a
hand-written frontend. Nothing to build, no framework to install.

--------------------------------------------------------------
1. WHAT YOU NEED
--------------------------------------------------------------
   - Node.js 18 or newer        (node -v)
   - MongoDB, one of these:
       a) local:  install MongoDB Community Server and make
                  sure it runs on 127.0.0.1:27017
       b) Atlas:  create a free cluster, add a database user,
                  and allow your IP under Network Access

--------------------------------------------------------------
2. SETUP (4 commands)
--------------------------------------------------------------
   cd campus-lost-found-portal
   npm install
   copy .env.example .env      (macOS/Linux: cp .env.example .env)
   npm run seed
   npm start

   Then open  http://localhost:5000

   If MongoDB is not reachable the server prints a clear message
   instead of starting half-broken. Read it before changing code.

--------------------------------------------------------------
7. COMMON PROBLEMS
--------------------------------------------------------------
   "MongoDB connection failed"
       -> mongod not running, or Atlas IP not allowed.
   "MONGO_URI is not set"
       -> you skipped copying .env.example to .env.
   Port 5000 already in use
       -> change PORT in .env.
   "Too many attempts" on login
       -> the rate limiter; wait 15 minutes or restart the server.
